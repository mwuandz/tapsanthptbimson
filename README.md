# Website tập san điện tử

## Xem thử
Mở `index.html` bằng trình duyệt.

## Đưa lên Vercel
1. Giải nén thư mục.
2. Upload toàn bộ thư mục lên một repository GitHub.
3. Trong Vercel chọn **Add New → Project** và import repository.
4. Framework Preset chọn **Other**, không cần Build Command.
5. Bấm **Deploy**.

## Điều khiển
- Điện thoại dọc luôn hiển thị hai trang sau bìa.
- Vuốt trái/phải để lật trang.
- Chụm hai ngón để phóng to tối đa 400%; kéo để di chuyển.
- Bấm nút phần trăm để trở về 100%.
- Máy tính dùng phím mũi tên hoặc các nút hai bên.
