# Website tập san 40 năm – THPT Bỉm Sơn

## Cách chạy
Mở `index.html` trực tiếp hoặc dùng VS Code Live Server.

## Đăng lên Vercel
1. Giải nén thư mục.
2. Đưa toàn bộ file lên một repository GitHub.
3. Import repository vào Vercel.
4. Framework Preset: Other; không cần Build Command.

## Thay ảnh hoặc thêm trang
Ảnh nằm trong `assets/pages/`. Đặt tên theo mẫu `page-01.webp`, `page-02.webp`... và sửa số lượng `21` trong `script.js`.
